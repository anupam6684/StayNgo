# StayNgo
StayNGo is a MERN stack web application for listing and booking rental stays


StayNGo 🏡

StayNGo is a MERN stack web application for listing and booking rental stays (like Airbnb).
It allows users to explore properties, create their own listings, leave reviews, and securely manage accounts.

✨ Features

🔑 Authentication & Authorization

User registration & login with Passport.js

Secure sessions with MongoDB session store

Flash messages for feedback

🏘 Property Listings

Create, edit, update, and delete property listings

Image upload support

Show details of each property

💬 Reviews & Ratings

Add reviews for listings

Delete or edit reviews (only by the author)

🗂 Database Integration

MongoDB Atlas for persistent data storage

Mongoose for schema & validation

🎨 Frontend

EJS templates with ejs-mate for layouts

Responsive design with CSS

⚙️ Other Tech

Express.js for server & routing

Method override for PUT/DELETE requests

Connect-flash for user feedback

Sessions stored in MongoDB

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript, EJS

Backend: Node.js, Express.js

Database: MongoDB Atlas (Mongoose ODM)

Authentication: Passport.js (Local Strategy)

Session Store: connect-mongo
